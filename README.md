# democofee
### 1. «Зерно» — интернет-магазин кофе (`coffee-shop/`)

Полноценный e-commerce с рабочей клиентской логикой:

- Каталог из 10 товаров (данные в JS-массиве, карточки рендерятся скриптом)
- Фильтры по типу и обжарке + сортировка по цене/популярности
- Корзина с сохранением в `localStorage` — переживает перезагрузку страницы
- Изменение количества, удаление позиций, промокод `ЗЕРНО10` (−10%)
- Расчёт доставки: бесплатно от 2 000 ₽, самовывоз — 0 ₽
- Форма оформления с валидацией (имя, телефон +7, адрес)
- Слайдер отзывов, анимации появления при скролле, мобильное бургер-меню

- Проект — демонстрационный: заказы и заявки никуда не отправляются,
все данные хранятся только в браузере посетителя.
